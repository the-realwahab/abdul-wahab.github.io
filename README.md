# Personal Website — Abdul Wahab

Simple, responsive single-page portfolio built with HTML and CSS to showcase skills, background, and social links.

## Features
- Dark, modern design with subtle motion and ambient effects
- Profile avatar with styled ring and status indicator
- Short summary and an About card with skill "pills"
- Social links (GitHub, LinkedIn, X, Instagram) and contact email
- Responsive layout for mobile and desktop

## Built with
- HTML5
- CSS3
- Google Fonts
- Font Awesome (icons)

## Quick start
1. Clone the repo:
   git clone https://github.com/the-realwahab/the-realwahab.github.io-main.git
2. Open locally:
   - Double-click `index.html` or
   - Serve with a simple HTTP server:
     python -m http.server 8000
     then open http://localhost:8000

## Customize
- Edit content in `index.html`.
- Tweak styles in `style.css` (colors, fonts, layout).
- Replace avatar at `img/` and update links in the social section.
